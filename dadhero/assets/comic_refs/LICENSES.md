# Comic style reference images -- sources and licenses

These are real public-domain Golden Age comic-book pages, used as an
additional visual reference (alongside the character's own reference
portrait) when a story is generated in the "Comic book" art style --
real panel composition, caption-box placement, and inking conventions
from an actual printed comic, not just a text description of one. Every
file below was sourced from Wikimedia Commons, verified individually
(each file's own page states its public-domain rationale), not scraped
in bulk or assumed.
